# complete-analysis-of-netflix-data-
Netflix Data Analysis &amp; Visualization project using Python, Pandas, Matplotlib, and Power BI. The project explores Netflix content trends, movies vs. TV shows, ratings, release years, genres, countries, and other key insights through data cleaning, EDA, and interactive dashboards.
🎬 Netflix Data Analysis & Visualization

📌 Project Overview

This project focuses on analyzing and visualizing Netflix movies and TV shows to discover meaningful insights and trends. The dataset is cleaned, explored, and transformed using Python, followed by interactive dashboard development in Power BI.

The project demonstrates practical **Data Cleaning, Exploratory Data Analysis (EDA), Data Visualization, and Business Intelligence** skills.

---

🎯 Objectives

* Analyze Netflix movies and TV shows
* Identify content trends over the years
* Compare Movies vs. TV Shows
* Analyze ratings and genres
* Explore content distribution by country
* Identify popular content categories
* Create meaningful visualizations and an interactive dashboard

---

📂 Dataset

The dataset contains Netflix content information with columns such as:

* `show_id`
* `type`
* `title`
* `director`
* `cast`
* `country`
* `date_added`
* `release_year`
* `rating`
* `duration`
* `listed_in`
* `description`

---

🧹 Data Cleaning

The dataset was cleaned and prepared for analysis by:

* Handling missing values
* Removing duplicate records
* Cleaning text fields
* Converting date columns
* Standardizing categorical values
* Checking data types
* Creating useful calculated columns
* Preparing the final dataset for visualization
